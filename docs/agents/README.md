# KINGKEN Agent Workspace

This folder defines the operating model for KINGKEN GLOBAL customer acquisition, service delivery, sales automation, international recruitment, deployment readiness, and compliance agents.

## Active agent suite

- `customer-acquisition-service-delivery.md` — executive operating charter and start-function instructions.
- `customer-acquisition-service-delivery.agents.json` — machine-readable agent registry, routing, approval, and escalation configuration.

## Production rule

Agents may collect, classify, draft, summarize, and route work. Agents must not complete high-impact business actions without human approval, including ticket issuance, hotel confirmation, visa submission, refund processing, payment approval, price changes, job offer issuance, candidate deployment, or contract signing.

## Communication systems

The intended channels are Gmail, Outlook, WhatsApp Business, website live chat, Google Drive, OneDrive, shared knowledge base, CRM sheets, finance trackers, booking portals, supplier systems, and recruitment databases.

Real credentials, tokens, API keys, customer records, passport data, and payment data must never be committed to the repository.
